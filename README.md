# 🕒 Real-Time Digital Clock

A lightweight and dynamic Digital Clock web application built using **pure JavaScript (Vanilla JS), HTML5, and CSS3**.

---

## ✨ Key Features
- ⏱️ **Real-Time Accuracy:** Live updating hours, minutes, seconds, and milliseconds.
- 🔄 **12-Hour Format:** Accurately converts standard 24-hour time into a user-friendly 12-hour format.
- ☀️🌙 **AM / PM Indicator:** Automatically detects and displays AM or PM.
- 🎯 **Clean Zero-Padding:** Formats single-digit numbers cleanly (e.g., `05` instead of `5`).
- ⚡ **Pure Vanilla JavaScript:** Built without any external libraries or frameworks.

---

## 🛠️ Technologies Used
- **HTML5** – Structure & Layout
- **JavaScript (ES6)** – Date Object, DOM Manipulation, and Timing Events (`setInterval`)
